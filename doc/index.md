# Documentation
This is the documentation of my homelab.
It is separated in 5 main topics:
- [Installation](installation.md): the steps, commands and explanations for setting up the basic environment
- [Configuration](configuration.md): how to configure the servers and the services on them, with configuration files and whatnot
- [Architecture](architecture.md): a description of the desired architecture with a diagram, and additionnally a security implications section with mitigation and implemented security measures
- [Resources inventory](inventory.md): a listing of the machines and equipment
- [Changelog](changelog.md): a log that is updated with what was done, at what date, by who, and the link to the relevant documentation
